# Game Design Rules: Midnight Snackdown

## Authoritative Reference

All mechanics, timing values and entity states must match [`docs/game-design-document.md`](../../docs/game-design-document.md). Change the document in the same commit as the rule it describes.

## Design Pillars

1. **Both panes are always visible.** Watching your rival is a skill, so hidden traps are shown only in their planter's pane.
2. **Every door is a choke point.** The house is a ring, so traps at doors matter and there is always another way round.
3. **Time is the penalty.** A knockout costs loot and clock time. Penalties only ever cost the raider who earned them.
4. **Slapstick, not violence.** Raccoons see stars, then wake up and carry on.
5. **Stay original.** New characters, settings, art and names are our own and are not modelled on an existing game or comic.
